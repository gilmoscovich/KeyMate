# KeyMate

אפליקציית Menu Bar מקומית למעבר מקיצורי Windows לקיצורי Mac. Swift / SwiftUI, macOS 14 ומעלה. 77 קיצורים, ללא רשת, חבילות חיצוניות או מפתח API.

## הפעלה

פתחו את `KeyMate.app` שנמצאת ליד תיקיית הפרויקט. לחיצה על סמל המקלדת בשורת התפריטים פותחת חיפוש. אפשר להעביר את האפליקציה לתיקיית Applications לפני הפעלת Launch at Login. האפליקציה אינה מופיעה ב־Dock.

חבילת ה־DMG שנבנית כאן היא אוניברסלית ומתאימה ל־Apple Silicon ול־Intel. היא נחתמת בחתימה מקומית (ad hoc); להפצה לציבור ללא אזהרות macOS נדרשים Developer ID ו־notarization.

## פיתוח ובדיקות

פתחו את `Package.swift` ב־Xcode, או הריצו מתיקיית הפרויקט:

```sh
./scripts/test.sh
./scripts/build-app.sh
./scripts/build-dmg.sh
open '../KeyMate.app'
```

הסקריפטים שומרים קבצי build במיקום מקומי; ניתן לשנות באמצעות `SHORTCUT_BUILD_DIR`. `build-dmg.sh` יוצר DMG ב־`outputs/releases`; פותחים אותו וגוררים את KeyMate אל Applications. מומלץ להפעיל את חבילת ה־app כדי להשתמש ב־Launch at Login. הרצה מתוך Xcode אפשרית לפיתוח, אך אינה מחליפה חבילת אפליקציה מותקנת.

## שימוש

- מקלידים בעברית או באנגלית, למשל: ״איך אני מצלם חלק מהמסך״, ״פתיחת טאב שסגרתי״, `how do I force quit` או `ctrl shift t`.
- חיצים למעלה/למטה בוחרים תוצאה. Enter מעתיק את הקיצור של התוצאה הנבחרת; אפשר גם ללחוץ על Copy.
- Escape סוגר את החיפוש. הפעולות עצמן אינן מבוצעות: כפתור ההעתקה מעתיק את סימון הקיצור בלבד.
- הגדרות: בחירת מראה כהה / בהיר / מערכת, החלפת שפת הממשק, הפעלה בכניסה למחשב וקיצור חיפוש גלובלי אופציונלי. בחירת המראה נשמרת ומוחלת מיד על חלונות האפליקציה; ברירת המחדל היא מערכת.
- הקיצור הגלובלי הוא Control–Option–K, כבוי כברירת מחדל. הוא פותח את אותו ממשק בחלון צף. macOS אינו מספק API ציבורי לפתיחה תוכנתית של חלון MenuBarExtra; לכן החלון הצף נפרד מהחלונית בשורת התפריטים.
- הקיצור עשוי להתנגש בקיצור של אפליקציה אחרת. במקרה של שגיאת רישום מופיעה הודעה, והאפשרות נשארת כבויה.
- Launch at Login משתמש ב־SMAppService ומציג את מצב הרישום בפועל; macOS עשוי לדרוש אישור בפריטי התחברות.

## מבנה

- `Sources/ShortcutCore`: מודל Codable, טעינת JSON, מנוע חיפוש ללא תלות בממשק.
- `Sources/ShortcutCore/Resources/shortcuts.json`: המאגר, כולל שמות ותיאורים בשתי שפות, מילות מפתח, קטגוריה וקיצורי Windows/Mac. ערך Windows ריק פירושו שאין מקבילה ישירה ברשומה.
- `Sources/ShortcutFinder`: סצנות SwiftUI, מצב האפליקציה, תוצאות, הגדרות ושירות hotkey מבוסס Carbon. אין האזנה לתוכן ההקלדה הגלובלי ואין צורך בהרשאת Accessibility.
- `Tests/ShortcutCoreTests`: בדיקות שלמות מאגר, דירוג, עברית/אנגלית, ניקוד, שגיאות כתיב, קיצורים, תוצאות ריקות וסדר דטרמיניסטי.

החיפוש מסיר ניקוד, מאחד אותיות סופיות, מנרמל אותיות וסמלי מקשים ומסנן מילות שאלה. התאמת קיצור מדויקת מקבלת עדיפות, אחריה ביטוי מלא, מילים, תחיליות ומרחק עריכה של תו אחד במילים שאורכן ארבעה תווים ומעלה. סף התאמה מונע תוצאות עבור רוב השאילתות הלא קשורות. זהו חיפוש לשוני מקומי מוגבל בכוונה, ולא מודל שפה שמבין כל ניסוח אפשרי.

## מקורות והבדלים בין יישומים

קיצורים נבדקו מול [מדריך קיצורי macOS של Apple](https://support.apple.com/en-il/102650). בממשק מוצגת הסתייגות לפי הקשר: קיצורי טקסט עשויים להשתנות ב־Word, קיצורי דפדפן עשויים להשתנות בין Safari ו־Chrome, והגדרות המשתמש יכולות לשנות קיצורי מערכת. קיצורי כיוון טקסט ויישור אינם זהים; רשומות היישור מתייחסות לעורכים התומכים בקיצורי macOS כמו TextEdit.

API: [MenuBarExtra](https://developer.apple.com/documentation/swiftui/menubarextra), [SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice).
