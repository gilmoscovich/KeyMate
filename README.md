# KeyMate
עברתם מווינדוס למק?
התרגלתם לקיצורי דרך במקלדת ועכשיו אתם לא יודעים איך לעשות אותם במק? KeyMate יעזור לכם למצוא אותם בקלות.

## הורדה והתקנה

1. הורידו את [הגרסה האחרונה](https://github.com/gilmoscovich/KeyMate/releases/latest).
2. פתחו את קובץ ה־DMG.
3. גררו את `KeyMate` לתיקיית `Applications`.
4. פתחו את KeyMate ולחצו על סמל המקלדת בשורת התפריטים העליונה.

## איך משתמשים

כותבים פעולה בשפה חופשית ומקבלים את הקיצור המתאים ל־Mac.

לדוגמה:

- `צילום מסך`
- `מחיקת מילה`
- `פתיחת טאב שסגרתי`
- `how do I force quit`
- `ctrl shift t`

אפשר גם לבחור קטגוריה, לעבור בין מצב בהיר, כהה או מערכת, ולהיעזר בחיפושים האחרונים.

## פרטיות

כל החיפוש והמאגר נמצאים על המחשב. KeyMate לא שולחת את החיפושים שלכם לרשת ולא דורשת חשבון.

## דרישות

macOS 14 ומעלה, על מחשבי Apple Silicon או Intel.
